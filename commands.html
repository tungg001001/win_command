常用 Windows 網路指令

1. ipconfig

查看 Windows 網路設定。

ipconfig

查看完整資訊：

ipconfig /all

2. ping

測試網路連線。

ping 8.8.8.8

測試 ESP32：

ping 192.168.1.100

3. nslookup

查詢 DNS。

nslookup google.com

4. tracert

查看封包經過的路由。

tracert google.com

5. arp

查看 ARP Table。

arp -a

6. netstat

查看目前 TCP / UDP 連線。

netstat -ano

7. route

查看 Windows Routing Table。

route print

8. netsh

查看 Wi-Fi 狀態。

netsh wlan show interfaces

9. curl

測試 HTTP 網頁。

curl https://example.com

10. PowerShell

測試 TCP Port。

Test-NetConnection 192.168.1.100 -Port 80
